# No1EqualsMe

[**Скачать готовое приложение Android 1.17**](https://raw.githubusercontent.com/fosyxx/no1equalsme/v1.17/No1EqualsMe.apk)

APK уже подписан и содержит все данные офлайн. Раздел **«Число π» находится на главном экране**. После установки откройте **No1EqualsMe 1.17**.

Версия 1.17 устанавливается рядом со старой 1.15: исходного ключа подписи старого приложения нет. Удалять старое приложение не нужно; его прогресс остаётся в нём и автоматически в новую установку не переносится. Следующие обновления 1.17 используют новый постоянный ключ.

Тренажёр слов, языков, Морзе, дактиля, стенографии и числа π. Веб-версия и Android используют один `index.html` и данные из `data/`.

## Запуск и проверки

Нужны Node.js 18+ и Python 3:

```sh
npm ci
npm run serve
npm test
```

Сайт доступен по адресу `http://localhost:8765`. Проверки включают загрузку 1500 слов, таймауты, распознавание всех эталонов обеих систем стенографии, реальные ID языков, восстановление облачного прогресса, смену дня и режим π. Широкий набор дополнительно проверяет существующие сценарии Морзе, карточек и настроек.

В разделе «Число π» на главном экране можно учить первые 1 000 цифр после запятой: экранная и физическая клавиатура, подсказки, удаление последней цифры, продолжение попытки и отдельный рекорд без ошибок и подсказок. Данные и прогресс доступны офлайн.

## Android

Исходники оболочки, сборка и подпись описаны в [android/README.md](android/README.md). `No1EqualsMe.apk` в корне — актуальный **подписанный установочный APK 1.17**, тот же файл, на который ведёт кнопка скачивания в Releases. Сборка не зависит от прежнего APK: все данные и ресурсы находятся в исходниках.

```sh
npm run test:apk
python3 android/verify_release.py --sdk "$ANDROID_HOME"
```

CI проверяет подпись, версию, запускаемую Activity и совпадение экранов/данных скачиваемого APK с исходниками. Устаревший APK в корне больше не проходит проверки.

Новая сборка исправляет выбор повреждённого кэша вместо встроенного словаря и зависание загрузки, поддерживает старые WebView без `String.padStart`/`AbortController`. Исправлены сравнение эталонов стенографии, координаты направляющих, обработка прерванных жестов, несовместимый пакет ГЕСС, ID и облачная синхронизация языков и обновление дневного плана после полуночи. Визуальное оформление сохранено.
