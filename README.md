# No1EqualsMe

Тренажёр слов, языков, Морзе, дактиля, стенографии и числа π. Веб-версия и Android используют один `index.html` и данные из `data/`.

## Запуск и проверки

Нужны Node.js 18+ и Python 3:

```sh
npm ci
npm run serve
npm test
```

Сайт доступен по адресу `http://localhost:8765`. Проверки включают загрузку 1500 слов, таймауты, распознавание всех эталонов обеих систем стенографии, реальные ID языков, восстановление облачного прогресса, смену дня и режим π. Широкий набор дополнительно проверяет существующие сценарии Морзе, карточек и настроек.

В «Ещё разделы → Число π» можно учить первые 1 000 цифр после запятой: экранная и физическая клавиатура, подсказки, удаление последней цифры, продолжение попытки и отдельный рекорд без ошибок и подсказок. Данные и прогресс доступны офлайн.

## Android

Исходники оболочки, сборка и подпись описаны в [android/README.md](android/README.md). Новая сборка сохраняет пакет `local.trainer.morse` и адрес WebView `https://morse.local/`, необходимые для сохранения прогресса при обновлении с исходной подписью.

`No1EqualsMe.apk` — прежний подписанный релиз 1.15; исправления в него не внесены. Проверять новый собранный APK нужно явно:

```sh
npm run test:apk -- android/build/No1EqualsMe-1.16-unsigned.apk
```

Новая сборка исправляет выбор повреждённого кэша вместо встроенного словаря и зависание загрузки, поддерживает старые WebView без `String.padStart`/`AbortController`. Исправлены сравнение эталонов стенографии, координаты направляющих, обработка прерванных жестов, несовместимый пакет ГЕСС, ID и облачная синхронизация языков и обновление дневного плана после полуночи. Визуальное оформление сохранено.
