No1EqualsMe — patch для репозитория (версия 1.15 / versionCode 16)

КАК ПРИМЕНИТЬ
Распакуйте архив в корень репозитория с сохранением путей и подтвердите замену файлов.

ИСХОДНИКИ, ДАННЫЕ И ТЕСТЫ
- index.html — выбор ГЕСС/Акопьян, рисование и чтение обеих систем, общий прогресс.
- steno/steno_block.js — синхронная копия блока стенографии.
- steno/generate_akopyan.py — генератор сильно сглаженных центрлайнов, векторных SVG и PNG.
- data/stenography-akopyan.json — пакет v3 из 28 знаков и геометрические шаблоны.
- assets/stenography/akopyan/*.svg — векторные знаки с кривыми Безье.
- assets/stenography/akopyan/*.png — 8×-отрисованные и сглаженные PNG-фолбэки.
- android/app/AndroidManifest.xml — версия APK 1.15 / code 16.
- test_morse.js, test_apk.js — регрессионные проверки.

ПРИМЕЧАНИЯ ПО СГЛАЖИВАНИЮ
Убрана мелкая дрожь исходных сканов: центрлайны проходят шесть проходов сглаживания и дополнительную гауссову фильтрацию; SVG и PNG используют одну и ту же кубическую кривую. Эталон в режиме рисования и резервный шаблон чтения тоже рисуются кривыми Безье. Толщина эталона уменьшена до 9 единиц, чтобы не скрывать форму. Рисуемый пользователем след и его затухание не менялись.

APK
No1EqualsMe.apk включён как готовая подписанная сборка. Это бинарный релизный файл; он не нужен для сборки исходников. Добавляйте его в репозиторий только если репозиторий хранит APK-релизы.
