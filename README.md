# No1EqualsMe

[**Скачать готовое приложение Android 1.18**](https://raw.githubusercontent.com/fosyxx/no1equalsme/v1.18/No1EqualsMe.apk)

APK уже подписан и содержит все данные офлайн. Раздел **«Число π» находится на главном экране**. После установки откройте **No1EqualsMe 1.18**.

Версия 1.18 обновляет установленную 1.17 поверх неё: пакет и ключ подписи сохранены, прогресс остаётся на месте. Рядом со старой 1.15 приложение по-прежнему устанавливается отдельно; данные 1.15 автоматически не переносятся.

Тренажёр слов, языков, Морзе, дактиля, стенографии и числа π. Веб-версия и Android используют один `index.html` и данные из `data/`.

## Запуск и проверки

Нужны Node.js 18+ и Python 3:

```sh
npm ci
npm run serve
npm test
```

Сайт доступен по адресу `http://localhost:8765`. Проверки включают загрузку 1500 слов, таймауты, распознавание всех эталонов обеих систем стенографии, реальные ID языков, восстановление облачного прогресса, смену дня и режим π. Широкий набор дополнительно проверяет существующие сценарии Морзе, карточек и настроек.

В разделе «Число π» первые 1 000 цифр учатся блоками по 3, 5 или 10: посмотреть → скрыть и вспомнить → соединить с предыдущим блоком. Повторения назначаются с интервалами 1, 3, 7, 14 и 30 дней, карта показывает состояние каждого блока. Проверка с начала и рекорд отделены от учебных попыток. Размер блока можно менять без потери прогресса. Прежние рекорд и попытка из версии 1.17 сохраняются. Всё работает офлайн.

## Android

Исходники оболочки, сборка и подпись описаны в [android/README.md](android/README.md). `No1EqualsMe.apk` в корне — актуальный **подписанный установочный APK 1.18**, тот же файл, на который ведёт кнопка скачивания в Releases. Сборка не зависит от прежнего APK: все данные и ресурсы находятся в исходниках.

```sh
npm run test:apk
python3 android/verify_release.py --sdk "$ANDROID_HOME"
```

CI проверяет подпись, версию, запускаемую Activity и совпадение экранов/данных скачиваемого APK с исходниками. Устаревший APK в корне больше не проходит проверки.

Новая сборка исправляет выбор повреждённого кэша вместо встроенного словаря и зависание загрузки, поддерживает старые WebView без `String.padStart`/`AbortController`. Исправлены сравнение эталонов стенографии, координаты направляющих, обработка прерванных жестов, несовместимый пакет ГЕСС, ID и облачная синхронизация языков и обновление дневного плана после полуночи. Визуальное оформление сохранено.
